## Sprechtext (EN, ca. 172 Wörter)

> Reading code is half of supervising agents. From any session, the files layer opens the project tree; text files open with syntax colors, Markdown renders, JSON and CSV get proper viewers, notebooks and archives open too. Hit control K anywhere and quick search finds files and inventory entries by name. The code search finds symbols across TypeScript and Python, and a result opens the file at the exact line; anchors survive reloads, so you can share a link to a line the same way you share a session. Language diagnostics mark broken files in red inside the tree, which is usually the fastest way to see what an agent actually broke. When an agent edits files, the changes tab shows the diff against the session's starting point, commit by commit if it committed. Feedback on a file goes straight back to the agent as context for the next turn. Nothing here phones home; indexing runs locally. The repository and the complete guide with screenshots of every page are linked on the endcard.
