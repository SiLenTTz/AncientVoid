## 1. Methode und Grenzen

- Echter Hub-Prozess mit den E2E-Fixtures (`e2e/support`, Adapter `opencode`/`claude`/`dummy`, Scratch-Webseite),
  Chromium, einmal als **Pixel 7** (1600×2560 @ Hochformat, Vorschau skaliert) und einmal **Desktop** (1280×720).
  Ein temporäres Skript führte die Journeys durch und wurde danach **nicht** committet (kein neuer Gate-Spec).
- Belege liegen als verkleinerte Bilder unter `docs/assets/p43-vorher-*.webp` (6 von 20 Aufnahmen; weitere
  Schritte nur beschrieben). Das ist ein Entwicklungs-Hub mit Fake-Providern: Texte wie „Antwort auf: …“ sind Testdaten.
- **Nicht belegt:** der CI-Anteil von Journey 4 („fehlerhaften CI-Test zurückgeben“) — der E2E-Hub hat kein GitLab;
  nur der Browser-Testteil wurde durchlaufen. Auch keine echte Pixel-/Gerätesicht (AC-P43-1 bleibt dafür offen).
  Beobachtungen zu Zählern sind Momentaufnahmen 0,4 s nach der Aktion (Poll-Verzug nicht ausgeschlossen).
- Abgleich P34/P35 gegen deren Epic-Status (beide umgesetzt, Live-Abnahme im P35-Endabnahme-Block offen), nicht gegen Code
  neu geprüft. Aussagen unten sind aus den Screenshots abgeleitet.

## 4. Mockups der vier Journeys (Soll, Textskizze)

**J1 Session starten:** Übersicht (leer) → Schaltfläche „Neue Session“ im Inhalt → Formular → Chat mit
einzeiliger Kopfzeile (Titel · Projekt · Modell, Rest hinter `⋯`), technische Systemzeilen eingeklappt.

**J2 Freigabe beantworten:**
```
┌ alpha · WERKZEUG Parser …  ⏸ ⏹ ┐   Kopfzeile bleibt frei
│ [ Bash: echo hallo-ancient… ]   │   genau EINE Darstellung der Anfrage
│ Laya: unauffällig · liest nur   │   (Karte oben fixiert, Toast entfällt
│ [ Erlauben ]  [ Ablehnen ]      │    wenn die Session offen ist)
│ … Verlauf …                     │
```
**J3 Diff revidieren:** Notiz anlegen → Notiz ist bereits zum Versand vorgewählt; Schaltfläche zeigt Anzahl
(„2 Befunde senden“), Stop nur im `⋯`-Menü, solange die Session bereit ist.

**J4 Test zurückgeben:** Browser-Auswahl, Review-Notiz und CI-Fehler erzeugen jeweils einen **Quellenchip** im Composer
mit Vorschau; „Senden“ bleibt eine bewusste Handlung. Browser-Fenster auf Handy mit Preset „Handy“ statt 1280×800.
